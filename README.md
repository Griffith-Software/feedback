# Griffith Software feedback

Public tracker for bug reports and feature ideas for the software at https://griffith.software.

All software is provided as-is. Opening a ticket does not create any obligation to respond, fix, or build anything, and does not entitle anyone to support. I read everything and usually act on it, but there are no promises or timelines.

Labels: `bug`, `enhancement`, `needs-triage`, `planned`, `fixed`, `wont-fix`.
